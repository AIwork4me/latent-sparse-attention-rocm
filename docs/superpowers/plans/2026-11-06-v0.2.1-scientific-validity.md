**Goal:** Repair the Dense-Decode baseline semantics, make the evidence chain fail-closed, re-run all matched benchmarks, classify upstream test failures, get CI green on the self-hosted gfx1151 runner, and deliver a draft PR with an independent review report and GO/NO-GO verdict.

**Architecture:** The decode fix lands in `pipeline.dense_read` (mask semantics chosen by query/cache length ratio) plus a new release-blocking gate G and pytest. Fail-closure lands in a shared gate-ID manifest enforced by both the adapter (receipt writer) and `run.validate_receipt` (receipt checker), and in a pure `campaign_exit_code` function. Upstream test failures are triaged against a committed classification manifest by a comparator that fails only on *new* failures. Headline tables are generated from validated receipts by `scripts/render_tables.py`.

**Tech Stack:** PyTorch 2.14.0+rocm10.1.0, Triton 3.8.0 (AMD build), pytest, gh CLI, GitHub Actions self-hosted runner.

**Spec:** the v0.2.1 mission statement (this conversation) + `docs/PORT_CONTRACT.md`.
