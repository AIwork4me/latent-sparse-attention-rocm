# Release Notes — v0.2.1 (DRAFT — publication requires owner approval; tag target = PR #1 merge commit, to be recorded)

## What this release is

`latent-sparse-attention-rocm` v0.2.1 is the **scientific-validity closure** of the ROCm (gfx1151) port of Prefrontal-AI's latent-sparse-attention: it repairs the wrong v0.2.0 dense-decode baseline, introduces fail-closed evidence validation, and re-runs every benchmark from validated receipts. It supersedes ALL v0.2.0 decode claims.

## The baseline defect (why v0.2.0 decode numbers are void)

The v0.2.0 dense-decode baseline masked a single-token (decode) query to key 0 and ran ~2.8× slower than a correct dense dispatch, inflating every sparse-vs-dense decode speedup. v0.2.1 fixes the baseline; gate G (dense decode/chunk == prefill tail, fp32/fp16/bf16) now pins the corrected semantics permanently (`docs/REVIEW_v0.2.1.md`, `docs/RESULTS_v0.2.0.md` carries the SUPERSEDED banner).

## Correctness guarantees (16-gate manifest, all PASS on gfx1151; auditor-recomputed)

Gates A, A2, B1, B2, C, D1/D2 (fp32/fp16/bf16), E, F, G (fp32/fp16/bf16) — bucket build vs oracle, hierarchy pairing, flat-select exactness/recall, tree-select exactness, sparse-read vs quadratic oracle, full-select == dense SDPA, decode-step == prefill-row, GQA, and the corrected dense baseline contract. Fail-closed: a receipt is claimable only with exactly these 16 ids, all PASS (`lsa_rocm_lab.gate_manifest`); the independent auditor recomputes every speedup from raw p50s (111/111 recomputed, 6/6 receipts APPROVED — `evidence/audit-v0.2.1.json`).

## Quantified results @ 32k ctx bf16, decode select+read (median of 3 independent runs, gfx1151 / ROCm 10.1.0 / torch 2.14.0+rocm10.1.0)

- **Block-sparse 3.9× vs dense**
- **D-LSA Flat 2.1× (spread 1.5–2.4×)** — later multi-seed work (v0.3.x) shows the flat-decode figure is seed-sensitive; cite the v0.3.x band (1.85–2.06×) for any forward-looking use
- **D-LSA Tree 0.9× — not faster than dense** (honest negative result)
- Prefill remains slower than dense at ≤32k (0.19×) — stated as-is

## Negative results / explicitly not claimed

- No end-to-end SGLang serving on gfx1151 (BLOCKED, documented causes).
- No NVIDIA-paper number presented as a Radeon result; no speedup that was not measured on this GPU.
- Upstream test triage: 203 pass / 7 classified / 0 unclassified — unclassified failures fail CI.
